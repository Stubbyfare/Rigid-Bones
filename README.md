# Rigid-Bones

A Blender addon for adding rigid bodies to rigs in Blender 5.2.2.

## Features
- Add rigid bodies to selected bones
- Supports Box, Sphere, Capsule, and Cylinder collision shapes
- Set mass, friction, and restitution
- Bake rigid body simulation to keyframes
- Panel in the 3D Viewport sidebar

## Installation
1. Download or clone this repository.
2. In Blender, open Edit > Preferences > Add-ons.
3. Click Install and choose the repository folder or ZIP file.
4. Enable the Rigid-Bones addon.

## Usage
1. Select an armature.
2. Enter Pose Mode.
3. Select one or more bones.
4. Choose the settings in the Rigid-Bones panel.
5. Click Add Rigid Body.
6. Optionally bake the simulation.

## Notes
- This addon is designed for Blender 5.2.2.
- The generated collision objects are created for each selected bone.
